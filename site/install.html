Install parda

One command. No settings. It takes effect in new terminals and restarted AI tools.

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/sundarshahi/parda/main/install.sh | sh

The script downloads the release for your machine from GitHub, checks its SHA-256 checksum, and runs parda install. Windows isn't supported yet; WSL 2 works as Linux.

From source

cargo install --git https://github.com/sundarshahi/parda
parda install

Needs Rust 1.85 or newer.

Check it's working

Open a new terminal, then:

parda status
● parda is running on http://127.0.0.1:7390
  http://127.0.0.1:7390/anthropic → https://api.anthropic.com
  http://127.0.0.1:7390/openai → https://api.openai.com/v1
  today (2026-11-21 UTC): 42 requests, masked 3 EMAIL, 1 PERSON, 2 SECRET
  log: /Users/you/.parda/log.jsonl

To see masking without any AI tool, pipe text through it:

echo "Ram Bahadur Thapa, ram@example.com, key sk-ant-api03-abcdefghijklmnopqrstu" | parda mask
[PERSON_924d28c3], email_a898b1e7@parda.invalid, key [SECRET_11e5e743]
parda: masked 1 EMAIL, 1 PERSON, 1 SECRET

Your stand-ins will differ: they are made with a key unique to your machine.

What install changes

Every change is marked so parda uninstall can remove it exactly.

WhereWhat
~/.parda/The program, your private key (key, readable only by you), where each route goes (upstreams.json) and the evidence log.
~/.zshenv, ~/.zshrc, ~/.bashrc, ~/.bash_profile, fish conf.dA marked block that sets ANTHROPIC_BASE_URL, OPENAI_BASE_URL, OPENAI_API_BASE and ANTHROPIC_API_BASE to parda.
~/.claude/settings.jsonenv.ANTHROPIC_BASE_URL, because Claude Code's own settings win over the shell. The old value is saved and becomes parda's upstream.
~/.codex/config.tomlA marked openai_base_url line at the top. An existing one is saved and becomes the upstream.
Login serviceA LaunchAgent (macOS) or systemd user service (Linux) that starts parda at login and restarts it if it stops.

If one of those already pointed somewhere other than the AI company (another proxy, a company gateway), parda keeps sending requests on to it. Nothing you had stops working.

Update

Run the install command again. Your key, and so your stand-ins, stay the same.

Uninstall

parda uninstall

This stops the service and puts every file above back the way it was. Your key and log stay in ~/.parda; delete the folder to remove them too. Restart your AI tools afterwards: until then they still point at parda and show a connection error.
