Use AI without handing it your secrets

parda sits between your machine and every AI service. Before a request leaves, it swaps API keys, passwords, names, emails and ID numbers for stand-ins. When the answer comes back, it puts the real values back. The AI never sees them; you never notice.

What each side sees

Built to be trusted

Nothing leaves to be checked

Detection runs on your machine with rules. No AI model, no cloud scanner, no telemetry. The table that maps stand-ins back to real values lives only in memory.

No settings

Install once. Claude Code, Codex, Aider and apps using the Anthropic or OpenAI SDKs are routed through parda automatically. Uninstall puts every file back exactly.

Fails closed

If parda isn't running, AI requests fail with a clear error instead of going out unfiltered. Bodies it can't read are refused, not forwarded.

Agents keep working

Each value always gets the same stand-in, so the AI can still tell one person from two, prompt caching keeps working, and real values come back into commands and file edits.

Light

A 2 MB program using about 2.5 MB of memory. Masking a large agent request takes a few milliseconds.

Speaks Nepali too

Names in Devanagari and romanised Nepali, Nepali ID labels like PAN and नागरिकता, and Devanagari digits — alongside English names and global formats.

Questions

Does parda send my data anywhere to check it?

No. parda checks everything on your machine with fixed rules. It never asks an AI model or any outside service whether something is sensitive, and it makes no network calls of its own. The only traffic it sends is the request your AI tool was already making, with the sensitive parts replaced.

Will my coding agent still work?

Yes. The AI sees a stand-in like [PERSON_8b01e4aa] instead of a name, and parda puts the real value back into the answer before your tool sees it — including into the commands and file edits an agent makes. parda also tells the model that stand-ins are placeholders to use as written. We tested this with Claude Code writing a file that contains a masked name, email and password: the file came out with the real values.

What happens if parda stops?

Your AI tools fail with a connection error until it is running again. That is on purpose: a request never goes out unfiltered. parda starts at login and restarts itself if it crashes.

Is the data anonymized?

No, and we don't claim it is. Stand-ins are pseudonyms: your machine can turn them back into real values. Under GDPR that is still personal data. What parda guarantees is narrower and checkable: the real values never leave your machine.

Does it slow anything down?

Barely. Masking a 150 KB Claude Code request takes about 6–8 ms on an Apple M2 Pro; the AI's own answer takes seconds. parda is a 2 MB program that uses about 2.5 MB of memory when idle and no CPU when nothing is happening.

Are there settings?

No. parda picks the right technique for each kind of data and routes your tools automatically. If something you already used sat between your tools and the AI (another proxy, a company gateway), parda keeps sending requests on to it.
