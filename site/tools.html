Supported tools

parda protects tools that send their AI requests to a base URL it can take over. Install sets that up for you.

ToolStatusHow
Claude Code (terminal, VS Code, JetBrains)Protected — testedANTHROPIC_BASE_URL in the shell and in ~/.claude/settings.json. Works with API keys and Claude subscriptions.
Codex CLIProtected — set up automatically, not yet tested by usopenai_base_url in ~/.codex/config.toml. Sign-in with ChatGPT is routed to ChatGPT's backend; please tell us how it goes.
AiderProtected — not yet tested by usOPENAI_API_BASE and ANTHROPIC_API_BASE
Your own apps using the Anthropic or OpenAI SDKsProtectedThe SDKs read ANTHROPIC_BASE_URL / OPENAI_BASE_URL when started from a shell.
Gemini CLIProtected — set up automaticallyGOOGLE_GEMINI_BASE_URL (Gemini API key) and CODE_ASSIST_ENDPOINT (sign-in with Google). Your own apps using Google's Gen AI SDK read GOOGLE_GEMINI_BASE_URL too. Tested with a fake provider and the real sign-in calls; Google now refuses personal-account sign-in for Gemini CLI, so use an API key there.

Apps started outside a shell

Apps opened from the Dock or a launcher don't read your shell's startup files. Claude Code is covered anyway through its settings file and Codex through its config file. Other apps need the variables set for them; see your system's documentation for setting environment variables for GUI apps.

GitHub Copilot with your own key

Copilot CLI, with an OpenAI key:

export COPILOT_PROVIDER_BASE_URL=http://127.0.0.1:7390/openai
export COPILOT_PROVIDER_API_KEY=your-openai-key
export COPILOT_MODEL=gpt-5

With an Anthropic key, add export COPILOT_PROVIDER_TYPE=anthropic and use http://127.0.0.1:7390/anthropic. See GitHub's guide to your own models in Copilot CLI.

VS Code chat: open Chat: Manage Language Models, choose Add Models then Custom Endpoint, and use http://127.0.0.1:7390/openai/chat/completions (Chat Completions) or http://127.0.0.1:7390/anthropic/v1/messages (Messages) as the model's URL.

We haven't tested Copilot ourselves yet; please tell us how it goes.

Already using a proxy or gateway?

parda keeps it. Install records where your tools sent requests before and forwards there, so you get parda's masking in front of your existing compression proxy, company gateway or data-residency endpoint. parda status shows each route.

For companies: lock it in

Claude Code's managed settings let an admin fix the base URL so users can't route around parda. See Anthropic's LLM gateway documentation.
